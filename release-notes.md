Terracotta 0.4.2 con el parche de Battly, compilado desde el código de este tag para los 13 destinos de Windows, Linux, macOS, FreeBSD y Android.

Incluye relé EasyTier, NoTun, anuncio LAN de Battly, API local protegida y reutilización del ejecutable EasyTier en Windows. Android se distribuye como biblioteca JNI .so; escritorio como paquete .tar.gz.

Cada archivo incluye su SHA-256 en SHA256SUMS y manifest-multiplatform.json. Son compilaciones verificadas por CI; no implican pruebas en dispositivos físicos de las 13 plataformas.
